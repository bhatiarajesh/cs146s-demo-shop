# Working in this repo

- Setup: none. Node 20 or newer, no dependencies.
- Tests: `npm test`. To check one suite: `node --test test/<name>.test.js`.
- Keep changes small and focused on the task. Open pull requests as drafts.
- Make every commit with these flags: `git -c user.name="Rajesh Bhatia" -c user.email="5156606+bhatiarajesh@users.noreply.github.com" commit`. Don't change git config.
- Back up claims with evidence: what you ran, and the results before and after.
- When you hand work back, use four headings: What changed, Evidence, What's left, How to continue.
