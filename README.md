# cs146s-demo-shop

A tiny online-shop backend, used as a live demo in Stanford CS146S (The Modern Software Developer), Fall 2026.

It exists to give a background coding agent a real job during the lecture: **one of the tests is flaky on purpose**, the way real test suites get flaky.

## Run the tests

Node 20 or newer, no dependencies:

```sh
npm test
```
